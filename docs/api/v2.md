# v2 Lean API

The v1 endpoint `/lyrics/` is unchanged. `/v2` adds a compact schema, ETag/304
support, explicit sync tiers, and small error envelopes. Both are served by
the same deployment; there is no separate v1 host or port.

## `GET /v2/lyrics`

| Parameter | Default | Description |
|---|---|---|
| `artist` | required | Artist name |
| `song` | required | Song title |
| `tier` | `line` | `plain`, `line`, `word`, or `syllable` |
| `allow_lower` | `true` | Serve the best available lower tier when the requested tier is missing |
| `lite` | `false` | Omit `artist`, `title`, `dur`, and `src` |
| `fields` | — | Comma-separated top-level fields to keep |
| `translate` | `false` | Translate with the instance's Groq key |
| `romanize` | `false` | Romanize/transliterate |
| `lang` | `en` | Target language |

### Line-level example

```bash
curl "http://127.0.0.1:9999/v2/lyrics?artist=Coldplay&song=Yellow&tier=line"
```

```json
{
  "v": 2,
  "src": "lrclib",
  "tier": "line",
  "artist": "Coldplay",
  "title": "Yellow",
  "dur": 267000,
  "lines": [[35660, "Look at the stars"], [38460, "Look how they shine for you"]]
}
```

### Word and syllable levels

Automatic word/syllable requests are routed only to **Lrcmux** and **Apple
Music**. If neither provider has the requested tier, `allow_lower=true`
returns the best lower tier from those providers or an already-cached richer
entry; `allow_lower=false` returns `404 {"err":"tier_unavailable"}`.

```json
{"lines": [[35660, "Look at the stars", [[35660, "Look"], [37200, "at"], [37700, "the"]]]]}
```

Syllable lines append one more level:

```json
{"lines": [[35660, "Look", [[35660, "Look", [[35660, "Lo"], [35800, "ok"]]]]]]}
```

Rules:

- Lines are `[start_ms, text]`. There is no per-line `id` and no `end_time`;
  clients derive the end from the next line.
- Integers are milliseconds.
- Nulls and false defaults are omitted.
- Errors are tiny: `{"err":"not_found"}`.

### Status codes

| Code | Meaning |
|---|---|
| `200` | Success |
| `304` | Unchanged (`If-None-Match` matched the ETag) |
| `400` | Invalid input or tier |
| `404` | `not_found` or `tier_unavailable` |
| `503` | Upstream providers unavailable / AI unavailable |

Every response carries an `ETag`. Send it back as `If-None-Match` to get a
bodyless `304`.

## `GET /v2/capabilities`

Reports the supported tiers, enabled providers, AI availability, and whether
optional compression is on.

## `GET /v2/health`

Reports per-provider breaker state, quota tokens, success/error/not-found
counters, p50/p95 latency, singleflight stats, negative-cache stats, and cache
stats. Provider failures are logged at `WARNING` with the provider name and
reason.

## Provider safety

Every provider call passes through one choke point (`src/core/providers.py`):

- Token bucket per provider, seeded from `.lyrica.config` RPM values and
  overridable with `LYRICA_PROVIDER_<NAME>_RPM`.
- Circuit breaker: opens after 5 consecutive transport failures, cools down
  for 30 seconds, then allows a single probe and requires two good probes
  before closing.
- Per-loop bulkhead (`LYRICA_PROVIDER_CONCURRENCY`, default 8).
- Metrics: latency, success, errors, not-found, rejected.

A provider can be disabled with `LYRICA_DISABLED_PROVIDERS=genius,apple_music`.
