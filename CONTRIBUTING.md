# 🤝 Contributing to Lyrica

First off, thank you for considering contributing to **Lyrica**! It’s community members like you that make open-source software great.

Whether you're fixing a bug, updating documentation, or proposing a new feature, all contributions are welcome and appreciated.

---

## 📜 Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md). Please read it to understand our community standards. Report any unacceptable behavior privately to **wilooper@proton.me**.

---

## 🛠️ How Can You Contribute?

### 1. Suggesting Ideas & Features
* Ideas and feature requests should be proposed in our **[GitHub Discussions](https://github.com/Wilooper/Lyrica/discussions)** tab under the **Ideas** category.
* Please search existing discussions and issues first to see if your idea has already been suggested.

### 2. Reporting Bugs
* Check the **[Issues](https://github.com/Wilooper/Lyrica/issues)** tab to see if the bug has already been reported.
* If it hasn't, open a new Issue providing a clear title, steps to reproduce the bug, expected vs. actual behavior, and relevant environment details.

### 3. Security Vulnerabilities
* **Do NOT open a public issue for security bugs.**
* Please follow our [Security Policy](SECURITY.md) to report vulnerabilities safely via GitHub Private Vulnerability Reporting or by emailing **wilooper@proton.me**.

---

## 🚀 Development & Git Workflow

Follow these steps to submit your code changes to Lyrica:

### Step 1: Fork the Repository
Click the **Fork** button at the top right of the [Lyrica Repository](https://github.com/Wilooper/Lyrica) page to create a copy under your own GitHub account.

### Step 2: Clone Your Fork
Clone your fork to your local machine and navigate into the project directory:
